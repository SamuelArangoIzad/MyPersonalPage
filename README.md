# Personal Portfolio – Web & App Designer

Welcome to the repository of my personal portfolio website.  
This project showcases my skills, services, and experience in **web development**, **UI/UX design**, and **application design**.  

The website is built as a clean, modern, and responsive presentation of the work I offer to clients and companies.

---

## 🚀 Features

- Modern responsive layout  
- Professional design focused on usability  
- Sections for services, projects, contact, and personal bio  
- Optimized structure for SEO  
- Ready to integrate with Wix, custom domains, or other hosting services  
- Scalable structure for future features (portfolio expansion, blog, pricing pages)

---

## 🛠️ Tech Stack

- **HTML5 / CSS3**
- **JavaScript**
